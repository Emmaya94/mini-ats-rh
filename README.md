# Mini ATS RH

## Objectif
Créer un outil simple de gestion des candidatures permettant d'automatiser le tri et le suivi des candidats.

## Fonctionnalités
- Ajout de candidats
- Scoring automatique basé sur des critères RH
- Attribution d'un statut (Prioritaire, À étudier, Refusé…)
- Filtrage et recherche
- Mise à jour du statut (workflow recrutement)
- Suppression de candidats
- Export des données en CSV
- Dashboard RH (suivi des indicateurs)

## Technologies utilisées
- Python
- Streamlit
- SQLite

## Logique métier
L'outil simule un processus de recrutement :
- Analyse des profils
- Priorisation des candidatures
- Suivi des étapes (entretien, recrutement)
